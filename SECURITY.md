# Security Policy

## Supported Versions

The following table outlines which versions of the project are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | ✅                 |
| 5.0.x   | ❌                 |
| 4.0.x   | ✅                 |
| < 4.0   | ❌                 |

## Reporting a Vulnerability 

We take the security of this project seriously and appreciate your efforts to responsibly disclose any issues.

- **Where to report**: Please submit vulnerabilities by opening a security advisory on GitHub or emailing the maintainers directly.  
- **Response time**: You can expect an initial response within **72 hours** of reporting.  
- **Updates**: We will provide regular updates on the status of your report until it is resolved.  
- **Resolution**: If the vulnerability is accepted, we will work on a fix and release a patched version as soon as possible. If declined, we will provide a clear explanation.  
- **Confidentiality**: All reports will be handled confidentially until a fix is released.  

Thank you for helping us keep the project safe and secure for all users.
