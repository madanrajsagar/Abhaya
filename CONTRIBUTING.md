# Contributing to Abhaya

Thanks for your interest in contributing! Here's how to get started.

## Setup

1. Fork this repo
2. Clone your fork
3. Frontend: `npm install` then `npm start` (Expo)
4. Backend: `cd backend && npm install` then `npm run dev`
5. Copy `.env.example` to `.env` and fill in your local values

## Making Changes

1. Create a branch from `main`
2. Make your changes
3. Test locally
4. Push to your fork and open a PR

## Code Style

- JavaScript (no TypeScript)
- React Native for frontend, Express for backend
- Keep components focused and small

## Reporting Issues

Open a GitHub issue with a clear description and steps to reproduce.
