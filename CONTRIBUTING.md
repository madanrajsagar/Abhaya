# Contributing to Abhaya

Thank you for your interest in contributing to Abhaya!

## Project Overview

Abhaya is a women safety application built using:

- React Native (Expo)
- Node.js
- Express.js
- Firebase
- Cloudinary
- Twilio

## Getting Started

### Clone the Repository

```bash
git clone <repository-url>
cd women-safety-gssoc
```

### Install Dependencies

```bash
npm install
```

### Backend Setup

```bash
cd backend
npm install
```

### Environment Variables

Create a `.env` file and configure the required API keys and credentials.

## Branch Naming Convention

Examples:

```text
feature/add-sos-history
fix/login-bug
docs/update-readme
```

## Commit Message Convention

Examples:

```text
feat: add emergency contact validation
fix: resolve login screen issue
docs: add contributing guide
```

## Pull Request Process

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Test the application
5. Commit your changes
6. Push the branch
7. Create a Pull Request

## Reporting Issues

Please include:

- Issue description
- Steps to reproduce
- Expected behavior
- Screenshots (if applicable)

## Code Style

- Write clean and readable code
- Follow existing project structure
- Use meaningful variable names
- Remove unused code before submitting

## Thank You

Thank you for contributing to Abhaya and helping make safety technology more accessible.
